# Система проведения хакатонов

**Студент:** Лаптев Егор, группа K3339  
**Репозиторий:** [GitHub](https://github.com/EgorLaptev/ITMO_ICT_WebDevelopment_tools_2025-2026)

## Описание

REST API на FastAPI для управления хакатонами, командами, задачами, отправками и оценками. Сервис поддерживает регистрацию, роли участников, создание команд, отправку решений и оценивание судьями.

## Стек

- **FastAPI** — веб-фреймворк
- **SQLModel** — ORM + Pydantic
- **PostgreSQL** — база данных
- **Alembic** — миграции
- **python-jose** — JWT-токены
- **passlib[bcrypt]** — хэширование паролей

## Сущности

| Сущность | Описание |
|----------|----------|
| `User` | Пользователь с ролью и паролем |
| `Hackathon` | Событие с задачами и командами |
| `Team` | Команда участников |
| `TeamMember` | Участник команды |
| `Task` | Задача хакатона |
| `Submission` | Отправка решения |
| `Evaluation` | Оценка судьи |
